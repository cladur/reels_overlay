# reels_overlay

Instagram Reels in a small always-on-top window beside your game, controlled by global hotkeys.
When locked, the window is click-through and never takes focus, so the game keeps your keyboard
and mouse. Pause, skip, like and change volume without alt-tabbing.

An unofficial tool, not affiliated with Instagram or Meta.

## Download

Get `reels_overlay.exe` from [Releases](../../releases) and run it. You don't need to install
anything else.

- Windows 10 or 11, 64-bit.
- The Microsoft Edge WebView2 Runtime. It comes with Windows 11 and with current Windows 10;
  otherwise, install it from Microsoft.
- The exe is not code-signed, so Windows SmartScreen may warn on first launch. Choose
  "More info" and then "Run anyway".

## First run

The window starts in **edit mode**. Log in to Instagram, drag the top bar to place the window,
drag its edges to resize it, then press `Alt+Shift+F1` to lock it. The login is remembered.

Run the game in **borderless** (or windowed) mode. Exclusive fullscreen draws over every other
window, the overlay included.

## Keys

| Key | Action |
| --- | --- |
| `F1` | pause / resume |
| `F2` / `F3` | next / previous reel |
| `F4` | mute / unmute |
| `Alt` + wheel | next (down) / previous (up) reel |
| `Alt` + middle click | like / unlike the current reel |
| `Alt+F2` / `Alt+F3` | volume down / up |
| `Alt+F1` | hide / show (hiding pauses) |
| `Alt+Shift+F1` | edit mode (move, resize, log in); press again to lock |

All of these can be changed in Settings. Keys without Ctrl/Alt/Win also work while Shift is
held, so they still fire while you sprint. While the app runs, Windows delivers these keys only
to it, so other apps no longer receive them (F2 stops renaming files in Explorer, for example).

The tray icon's menu has Settings, edit mode, show/hide, reload and quit. Double-click the icon
to open Settings.

## Settings

Open Settings from the tray icon, or start the app with `reels_overlay.exe --settings`.

- **Keys:** click a box and press the combination. Backspace clears it and Esc cancels. A
  combination that another action already uses moves to the new action. Bare typing keys and
  Windows' own combinations (Alt+F4, Alt+Tab) are refused.
- **Mouse:** the modifiers to hold for wheel scrolling and middle-click liking. Ticking none
  turns mouse control off.
- **Sound:** volume and mute.
- **Display:** GPU rendering. It is off by default, because the overlay's GPU work while
  scrolling can cause FPS dips in GPU-bound games. Changing it restarts the app.

Hotkeys keep working while the Settings window is open. They pause only while a key box is
recording. Save applies immediately. If another app already owns a combination, the window says
so and stays open so you can pick another.

Everything is stored in `%APPDATA%\reels_overlay`: `config.json` holds your settings and
window position, and `WebView2` holds the Instagram login. Delete the folder to reset.

## Games and anti-cheat

The overlay is a separate window. It injects nothing into games and reads no game memory. Its
only system-wide input access is the global hotkeys and a low-level mouse hook, which watches
for the modifier+wheel and modifier+middle-click combinations. Untick all mouse modifiers in
Settings to remove the hook. As with any third-party tool, use it at your own risk.

## Building

Requires the .NET 10 SDK.

```
dotnet build -c Release
bin\Release\net10.0-windows\reels_overlay.exe
```

Release exe: `dotnet publish -c Release -o publish` produces a single self-contained
`publish\reels_overlay.exe` for win-x64.

`app.ico` is generated by `make_icon.ps1`.

## How it works

- A WinForms window hosts WebView2. It uses a phone user agent, so Instagram serves its mobile
  reels layout.
- Locked window styles: `WS_EX_LAYERED | WS_EX_TRANSPARENT` (clicks pass through) and
  `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW` (no focus, no taskbar or Alt-Tab entry). The window
  reasserts topmost every 2 s. Edit mode adds its frame and drag bar outside the page, so
  toggling it does not resize Instagram.
- Focus emulation (`Emulation.setFocusEmulationEnabled`) makes the page always believe it has
  focus. Instagram pauses the reel when its window blurs, and leaving edit mode hands focus
  back to the game.
- Touch emulation is on, and a step is a touch swipe sent with DevTools
  `Input.synthesizeScrollGesture`. That is trusted input delivered straight to the page,
  without focus or moving the cursor. Instagram's mobile reels page only advances and loads
  more reels on swipes. Wheel or scripted scrolling only slides through the first batch of
  about seven reels. If the reel in the URL has not changed 0.9 s after a swipe (for example,
  because it landed while Instagram was loading the next batch), the app swipes once more.
- Like taps the current reel's like button, found by its "Like"/"Unlike" label. The tap is a
  raw DevTools touch-down/touch-up pair (`Input.dispatchTouchEvent`), which produces the
  `click` the button listens for. `Input.synthesizeTapGesture` does not produce that click.
- `control.js` is injected into the page. It enforces pause, mute and volume on every
  `<video>`, restarts the last reel if nothing plays while locked, and hides scrollbars. It
  never scrolls the page and never chooses which reel plays; Instagram does that.
- Rendering and video decoding are in software (`--disable-gpu`) unless GPU rendering is on.
  The overlay then uses almost no GPU time. It costs about 13% of one CPU core while a reel
  plays and about 55% of one core during swipes, measured on a 16-thread CPU.
- The WebView2 browser processes run at below-normal priority, so the CPU work of loading
  reels yields to the game.
- Windows holds every mouse event, including the game's, until a low-level hook returns. So the
  mouse hook runs on its own high-priority thread that only reads the modifier keys and posts
  any action to the UI thread without waiting.

## Debugging

- `REELS_OVERLAY_DEVTOOLS_PORT` (for example `9339`) exposes the page on
  `http://127.0.0.1:<port>` through the Chrome DevTools Protocol. While it is set, any local
  program can read and control the logged-in page, so only set it while diagnosing.
- `REELS_OVERLAY_DIR` points the app at a different settings and profile folder.
